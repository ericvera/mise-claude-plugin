# Driver overlay on the draft scorecard

The draft (scorecard.md) trims v2: 34 shrink, 19 keep, 7 cut; median run −21% output, small run 11 → 9 spawns and 74 → 51 active minutes. That is not the 80/20 the owner asked for. Many "earned its cost" cells are arguments ("prevents unbounded burn"), not measured value. Cut-by-default says an argument is not evidence. This overlay goes further where the draft kept something on an argument. Where the overlay is silent the draft verdict stands.

The last column is the result of the adversarial defence (defence.md), which searched the verbatim records for real catches each cut would lose.
